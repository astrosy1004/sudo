# 라즈베리파이 프로젝트 전시관

수업 6개 팀의 작품을 VR 전시관처럼 둘러보는 정적 웹 서비스입니다. 빌드 없이 순수 HTML + CSS + 바닐라 JS(CSS 3D)로 동작합니다.

## 구성

```
sudo/
  index.html        # 화면 뼈대 (3D 무대, 상단/하단 메뉴, 영상·PPT 모달)
  assets/styles.css # CSS 변수 + 다크 모드 + 3D 방/로비 스타일
  assets/app.js     # 최상단 TEAMS 배열(팀 데이터) + 장면 생성 + 카메라 조작
  assets/class-data.js # 수업 전시실 내용 (패들렛 정리본)
  assets/media/     # 동작 영상·PPT 이미지/PDF를 넣는 폴더
  .nojekyll
```

## 관람 방법

- **로비**: 6개 팀 입구가 원형으로 놓여 있습니다. 카드를 클릭하면 해당 프로젝트 룸으로 입장합니다.
- **프로젝트 룸**: 마우스/터치 드래그로 둘러보기, 휠 또는 ↑↓ 키로 앞뒤 이동, ← → 키로 회전.
  - 뒷벽: 동작 영상 스크린, PPT 카드, 핵심 기술
  - 왼쪽 벽: 기술 구성 카드
  - 오른쪽 벽: 팀 소개 안내판
  - 중앙: 전시물(1팀은 서빙 로봇)과 안내 데스크
  - 뒤쪽 벽: 로비 / 이전 팀 / 다음 팀 문
- 하단 메뉴에서 `동작 영상`, `PPT 보기`, 이전/다음 팀, 전체 화면을 바로 쓸 수 있습니다.
- 주소 끝 `#t1` ~ `#t6` 으로 특정 팀 룸에 바로 들어갈 수 있습니다.

## 수업 전시실 (`#class`)

로비 정면의 초록색 **수업** 카드 또는 하단 `수업 전시실` 버튼으로 입장합니다. 패들렛 「[수도전기]라즈봇&앱인벤터」의 내용을 6단계 로드맵 + 시험/프로젝트로 정리해 보여 줍니다.

- 뒷벽: 수업 개요 수치, 키워드, 패들렛 원본 링크
- 왼쪽 벽: 학습 로드맵 카드 (누르면 상세 자료 창)
- 오른쪽 벽: 5반/6반 미션 진행표 (행을 누르면 해당 단계 자료)
- 내용 수정: `assets/class-data.js` 의 `CLASS_INFO`, `TOPICS`
- 학생 이름·학번과 계정 비밀번호는 공개 페이지라 일부러 뺐고, 패들렛 첨부파일 링크는 만료되므로 원본 패들렛으로 연결합니다.
- 패들렛이 갱신되면 이 파일을 직접 고쳐야 합니다. (자동 동기화 아님)

## 팀 정보 수정 (app.js 최상단 `TEAMS`)

| 항목 | 설명 |
| --- | --- |
| `title`, `tagline`, `desc`, `members` | 룸 간판·안내판 문구 |
| `accent` | 팀 대표 색상 |
| `parts` | 기술 구성 카드 (`name`, `icon`, `text`). icon: `chip` `motor` `ir` `line` `matrix` |
| `video` | 동작 영상 경로 (`./assets/media/t1.mp4`) 또는 YouTube 주소. 비우면 안내 화면(1팀은 라인트레이싱 시뮬레이션 데모) |
| `slides` | 이미지 배열 `["./assets/media/t1/1.png", ...]` 또는 PDF 경로/임베드 주소. 비우면 `outline` 으로 자동 슬라이드 생성 |
| `outline` | 자동 생성 슬라이드 내용 `{ h: "제목", b: ["항목", ...] }` |

- 현재 **1팀(애슐리퀸즈 음식 서빙 로봇)만 입력**되어 있고 2~6팀은 자리 표시 상태입니다. 주제를 알려 주시면 채워 넣을 수 있습니다.
- PPT는 `.pptx` 를 브라우저에서 직접 열 수 없으므로 **PDF로 내보내거나 슬라이드를 PNG로 저장**해 넣는 것을 권장합니다.
- 영상은 용량이 크면 YouTube(일부 공개/미등록)에 올리고 주소를 넣는 편이 GitHub Pages에 적합합니다.

## 로컬 확인

`index.html` 을 브라우저로 직접 엽니다. (PDF/영상 파일 로드는 브라우저에 따라 로컬 서버가 필요할 수 있습니다: `python -m http.server`)
